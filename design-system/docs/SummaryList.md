# SummaryList

A white card of key/value rows.

Used for the settings screen's plain-words account of what leaves the phone. Use an em dash for empty values.

```tsx
<SummaryList items={[
  { label: 'Mascot', value: 'Basil' },
  { label: 'You like', value: 'courgette, feta' },
]} />
```
